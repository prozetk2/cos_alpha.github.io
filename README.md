# Cos_Alpha — phiên bản 6

Toàn bộ mã nguồn HTML, CSS và JavaScript nằm trong index.html; các ảnh đi kèm nằm cùng thư mục.

## Chạy trên máy
Giải nén và mở index.html trong trình duyệt. Hoặc chạy `python -m http.server 8000` trong thư mục rồi truy cập http://localhost:8000.

## GitHub Pages
Đưa index.html, portrait.png và avatar.jpg vào thư mục gốc của nhánh dùng để deploy GitHub Pages.
